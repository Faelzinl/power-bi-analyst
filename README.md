# Desafio Power BI Analyst

Projeto desenvolvido durante o bootcamp Power BI Analyst.

## Projeto

O desafio consiste na criação de um dashboard utilizando dados financeiros, apresentando:

- Vendas e unidades vendidas por país
- Lucro por país
- Lucro por segmento

## Ferramenta utilizada

- Microsoft Power BI

## Arquivo

O arquivo `Desafio_Power_BI.pbix` contém o projeto completo desenvolvido no Power BI.
